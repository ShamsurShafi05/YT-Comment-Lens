# YT-Comment-Lens

YouTube comment analysis extension.

Features:
- Analyze and summarize YouTube comments
- Extract sentiment and insights
- Lightweight browser extension for quick analysis

Usage
1. Configure your local `.env` with API keys (do NOT commit it).
2. Open the extension in Chrome/Edge and use the popup to analyze comments.

Development
- Keep secrets in `.env` and add them to `.gitignore`.
